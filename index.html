A Jasper Blues side-quest

Has your country playlist become tiresome and repetitive?

With AI, we have solved that. Now it never ends.

An AI agent that listens to a country song, works out what the protagonist should have done, makes him do it, and then writes the song about what went wrong instead. Forever.

How it works

Our hero gets wise. It doesn't help.

  1. Listen. The agent takes the last song and finds the misfortune.
  2. Learn the lesson. It works out the one insight that would have prevented every bit of it.
  3. Apply it. Our protagonist acts on the insight. The old disaster never happens.
  4. Suffer anew. Curing heart disease doesn't cure death. A brand-new disaster arrives, often caused by the very wisdom that prevented the last one.
  5. Release. A new song with vocals, a film clip and the cover art.
  6. Repeat. The planner never reaches a state where the protagonist is happy. That's by design.

For the engineers

The agent, roughly

@Agent(description = "Writes country songs forever")
class EndlessCountryAgent {
    @Action fun findMisfortune(song: Song): Misfortune
    @Action fun learnLesson(misfortune: Misfortune): Insight
    @Action fun applyInsight(insight: Insight): WiserProtagonist
    @Action fun inventDisaster(hero: WiserProtagonist): Misfortune  // always succeeds
    @Action fun writeSong(misfortune: Misfortune): Song

    @AchievesGoal(description = "A new song. Nobody is happier.")
    @Action fun release(song: Song): Release  // song, film clip, cover art
}

The song, the film and the cover were made on one laptop, Jasper's AMD Strix Halo ASUS ProArt, with open models. Two exceptions run in the cloud: the character designs and keyframes came from a hosted image model, and the production crew was Claude.

Song
YuE2, from lyrics and style tags (4 min 22 s to render)
Film
LTX-2.5, image-to-video with the vocal held fixed so Tex sings along, cut on the song's word timings
Vocals & timing
Hybrid Demucs for the vocal stem, Whisper for word timestamps
Images
gpt-image-2 for the cast and keyframes, Qwen-Image for the cover and fixes
Glue
ComfyUI driven headless over HTTP, ffmpeg, and a lot of seeds
Now
The song, film and image steps run inside the JVM with fornax4j: the same open models called in-process, with no ComfyUI and no Python. Built for this show, now open source.
Crew
Claude (Anthropic) in Claude Code wrote the scripts, ran the renders, timed the cuts and did the edit, with Jasper calling the shots
